# PLP Python Week 4 - Functions

- `welcome.py`: A `welcome()` function that returns a greeting, called three times instead of repeating the same line.
- `toolbox.py`: Three small functions: `double()` doubles a number, `is_pass()` checks if a score is 50 or more, and `greet()` builds a greeting with an optional default.

The hardest function to write was `greet()` because I had to remember the comma, the space and the exclamation mark, and understand how the default greeting works.
